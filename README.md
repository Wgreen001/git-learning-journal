# My Github Journal

## Entry 1.

This video documents my full walkthrough of the Module 2 Git assignment. In the recording, I create multiple files, set up a .gitignore file, and show how Git handles ignored items during status checks. I move through the textbook exercises by reviewing my project history with git log, checking changes with git show, and listing the commits I made. I also demonstrate how to move between commits using git checkout without altering the project, and I finish by amending a commit message to show how to cleanly rename a commit. At the end of the video, I review Git best practices, including how to write clear commit messages, what to do when committing, what to avoid, and a brief explanation of how Git functions overall.
